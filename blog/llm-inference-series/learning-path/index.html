15 · 学习路径与资源地图：从入门到精通的阶梯 + 职业市场

Tim Chan 发布于 2026 年 9 月 14 日

这是系列的收官篇。前面 14 篇给了知识全景，这一篇给"怎么从零走到能上手"的路径——分阶段的学习阶梯、必读资源、练手项目，以及当前 inference engineer 的职业市场现实。

一、五阶段学习阶梯

阶段一：奠基（1-2 个月）

目标：理解推理到底在算什么，能本地跑通一个模型。

  • 搞懂 Transformer 前向、attention、autoregressive 解码（本系列 02 篇）。
  • 理解 prefill vs decode 两阶段、memory-bound 本质。
  • 本地跑：用 llama.cpp 或 MLX 在自己机器上跑一个 7B 量化模型，用 OpenAI 兼容 API 调。
  • 学会算 KV cache 大小（第 3 篇公式）。

练手：

# 用 llama.cpp 跑 Llama-3.1-8B Q4_K_M
llama-server -m Llama-3.1-8B-Q4_K_M.gguf -c 8192 --port 8080
curl http://localhost:8080/v1/chat/completions ...

# 或 MLX
mlx_lm.server --model mlx-community/Meta-Llama-3.1-8B-Instruct-4bit

里程碑：能解释"为什么 decode 比 prefill 慢"，能本地跑通并调 API。

阶段二：框架与量化（1-2 个月）

目标：会用主流框架，懂量化权衡。

  • 系统学 vLLM：装、启动、关键参数、连续批处理、prefix cache。
  • 量化实操：同一个模型跑 FP16 / INT8 / INT4，测延迟和 perplexity 对照。
  • 理解 PagedAttention、continuous batching、prefix caching 原理（第 3、6 篇）。
  • 试 SGLang，对比结构化输出场景。

练手：

# vLLM 服务 + 压测
vllm serve Qwen/Qwen2.5-7B-Instruct --enable-prefix-caching
# 用 vllm bench 或 k6 压测，画 TTFT/TPOT vs 并发曲线

里程碑：能给一个模型选量化方案并用数据支撑（延迟×成本×质量三角）。

阶段三：性能工程（2-3 个月）

目标：能定位瓶颈、正确测量、做有边界的优化。

  • 学 profiler：Nsight Systems / Compute，看 timeline 和 roofline。
  • 实操第 10 篇的测量陷阱：写一个 TTFT 采集器，对比缓冲读 vs 增量读，亲眼看 185ms 差异。
  • 实操 trace 归因：profile 时按 PID 过滤，看无关进程占比。
  • 上 speculative decoding，测接受率和净加速。
  • 建一个最小证据目录（第 14 篇），给一次实验封 commit + hash。

练手：复现 Inference Lab 的 TTFT HTTP 客户端实验——写两个采集器版本，自己测出缓冲延迟。

里程碑：能说清一个性能问题卡在 prefill 还是 decode、是带宽还是算力、是调度还是 kernel，并给出有边界的优化结论。

阶段四：生产与成本（2-3 个月）

目标：能上线、扛得住真实流量、控得住成本。

  • 学 K8s 部署 vLLM：Deployment + Service + HPA/KEDA autoscaling。
  • 压测找拐点，设 SLO，建监控仪表盘（第 12 篇四层指标）。
  • 实操灰度发布与回滚、故障注入。
  • 成本优化：试 spot 混合、智能路由、预算门控（第 11 篇）。

练手：在一个云上（Modal/RunPod/自建 K8s）部署一个多副本 vLLM 服务，配 autoscaling + 监控 + 灰度。

里程碑：能独立把一个模型从"本地能跑"做到"生产可服务 + SLO 达标 + 成本可控"。

阶段五：前沿与专精（持续）

目标：跟进前沿，在某方向做深。

  • disaggregated inference、MoE 服务、KV cache 跨副本共享、新一代投机解码（第 13 篇）。
  • 读 paper + blog，本地小模型复现验证。
  • 选一个方向深做：长上下文 / MoE / 量化 / agent 服务 / 可观测性。

里程碑：能给团队引入一个前沿优化并有数据支撑，能评审别人的性能声明挑出边界问题。

二、必读资源地图

2.1 基础论文（理解原理）

  • Attention Is All You Need（Vaswani 2017）：Transformer 原始。
  • FlashAttention（Tri Dao 2022/2023）：attention kernel 优化奠基。
  • vLLM / PagedAttention（SOSP 2023）：连续批处理 + 分页 cache。
  • GQA（Ainslie 2023）：分组查询注意力。
  • Speculative Decoding（Leviathan 2023）：投机解码奠基。

2.2 框架文档与 blog

  • vLLM 文档（docs.vllm.ai）：最全的推理工程参考。
  • SGLang 文档 + LMSys blog（lmsys.org/blog）：前沿落地最快。
  • llama.cpp README + docs：GGUF/边缘/Apple Silicon。
  • MLX 文档（ml-explore.github.io）：Apple Silicon 统一内存。
  • TensorRT-LLM 文档：NVIDIA 极致 kernel。

2.3 实践范本

  • Inference Lab 8 篇（siddhantkhare.com/writing，inference-lab 分类）：本系列反复引用的实证范本。它不是 API 教程，是"这个岗位怎么思考"的示范。强烈建议逐篇精读。
  • LLMTraceFX（GitHub: Siddhant-K-code/LLMTraceFX）：证据优先的推理观测工具包，Inference Lab 文章的代码底座。读它的 evidence bundle / verifier 设计，学第 14 篇的证据体系。

2.4 社区与跟进

  • vLLM / SGLang 的 GitHub Discussions + Slack：问题和前沿第一手。
  • Hugging Face：量化模型库（TheBloke、mlx-community）+ 模型卡。
  • LMSys / Neural Magic / NVIDIA blog：优化实战。
  • arxiv：cc.ides（投机解码）、KV cache compression、attention 新作。

2.5 课程

  • Stanford CS324（LLM） / CMU 11-868（LLM Systems）：学术侧系统视角。
  • 各框架官方 tutorial / example：动手侧。

三、练手项目清单（由易到难）

  1. 本地跑通：llama.cpp/MLX 跑 7B 量化，OpenAI API 调通。
  2. 量化对照：同模型 FP16/INT8/INT4，画延迟×质量对照表（带 perplexity）。
  3. vLLM 服务：单卡 vLLM + prefix cache + k6 压测，找拐点。
  4. TTFT 采集器：写缓冲版 vs 增量版，实测 185ms 差异（复现 Inference Lab）。
  5. trace 归因：profile 一次负载，按 PID 过滤，看无关进程占比。
  6. KV cache 审计：写一个 token oracle，核对引擎 cache hit 报告（复现 Inference Lab）。
  7. 多卡部署：TP=2 跑 70B 量化，配 K8s + autoscaling + 监控。
  8. 证据目录：给一次实验建 evidence dir + SHA256SUMS + claim matrix（第 14 篇）。
  9. 投机解码：开 EAGLE/n-gram，测接受率 + 净加速 + 输出一致性。
  10. 成本路由：写质量门控路由器，简单走小模型复杂走大模型，测 correct cases/$。

做完这 10 个，你已经是有实战能力的 inference engineer。

四、职业市场现实

4.1 岗位需求

inference engineer / LLM inference engineer / ML infra engineer（推理方向）岗位 2024-2026 快速增长。需求集中在：

  • 大模型公司（OpenAI/Anthropic/Google/Meta/字节/阿里/腾讯/Moonshot/DeepSeek/GLM/智谱）。
  • AI infra 公司（Modal/Together/Anyscale/Replicate/硅基流动/火山引擎）。
  • 自建大模型能力的金融/医疗/法律/电商企业。
  • agent 平台公司（需要 agent 服务优化的）。

4.2 JD 常见要求（归纳）

硬技能： - 精通 Python + C/C++（kernel/性能工作要 C++）。 - 深度学习框架（PyTorch 必备）。 - 推理框架实操（vLLM/TensorRT-LLM/SGLang 至少一个深）。 - GPU/CUDA 编程 + 性能调优（Nsight）。 - 量化、KV cache、batching 原理。 - 分布式系统 + K8s。

软技能： - 系统思维（瓶颈归因、容量规划）。 - 实验纪律（可复现、有边界、null≠zero）。 - 成本意识（花公司的钱像花自己的）。

4.3 背景

常见来源背景：

  • ML infra / 分布式系统工程师转推理。
  • C++/系统性能工程师转 GPU。
  • 研究 side 的 ML engineer 往工程转。
  • 算法竞赛 / kernel 优化背景。

4.4 怎么证明自己

  • 做上面 10 个练手项目，开源出来（GitHub 是最好的简历）。
  • 给 vLLM/SGLang/llama.cpp 提 PR（开源贡献是强信号）。
  • 写技术博客（像 Inference Lab 那样有边界的实验记录）。
  • 能在面试讲清楚一个你做过的性能优化：瓶颈→假设→实验→数据→边界。

4.5 薪资（量级，因地区/级别差异大）

  • 北美：senior $200k-500k+ 总包（顶级公司更高）。
  • 中国一线：senior 60w-200w RMB 年薪（顶级大模型公司更高）。
  • 初级/转岗：低于 senior，但增长快（这个岗位供小于求）。

注意：数字是量级，别当承诺。真正决定价值的是你能给业务省多少延迟/成本——这个杠杆效应是这岗位薪资高的根因。

五、心态与方法论

最后，回到 Inference Lab 体现的几条心态，这是比任何技术都重要的：

  1. 对边界的执念。每个数字问"它到底测了什么"。cache hit≠跳过计算，权重放得下≠跑得动，trace 总数≠负载数，break-even 建模≠观测。

  2. 把"这不证明什么"写出来。不是谦虚，是工程严谨。不写边界，迟早过度声明把团队带沟里。

  3. 独立 oracle 校验。不只信系统自己的报告。

  4. 证据可复现。精确到 commit + SHA-256。只有可复现才能回归。

  5. 预算纪律。花真金白银前 dry-run + 预留最坏预算 + 逐条核对。

  6. 可比性来自契约不是视觉。别把不可比的数字放一张表当可比。

  7. fail closed。证据不一致时不出报告，宁慢不发坏。

这七条，是"会跑 vLLM"和"是 inference engineer"的真正分水岭。技术会迭代，这些心态常青。
